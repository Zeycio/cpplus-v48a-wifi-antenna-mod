# Images

Each figure shows one of these illustrations. The filenames are wired into
`index.html`, so an image appears automatically once present (it sits on top of the
fallback line-drawing).

| Filename                   | Shows                                              |
|----------------------------|----------------------------------------------------|
| `fig01-camera.png`         | The CP Plus V48A camera on its mount.              |
| `fig02-mainboard-wifi.png` | Wi-Fi board close-up (📶 symbol, code, `2R2` / IC).|
| `fig03-solder-feed.png`    | Solder-joint macro (green window, copper L-trace). |
| `fig04-rpsma-mounted.png`  | RP-SMA connector / coaxial-cable diagram.          |
| `fig05-board-lens.png`     | Round main board with the lens (`PUYA` chip).      |
| `hero-before-after.png`    | Before → after banner near the top of the page.    |

## Notes
- Filenames are **case-sensitive** on GitHub Pages — match them exactly.
- Images show at their **natural aspect ratio** (height capped so tall board shots
  don't dominate the page, nothing cropped) and replace the fallback drawing.
- To swap any image, just overwrite the file with the same name.
